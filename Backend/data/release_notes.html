Knovera Enterprise Release Notes

Version 2.4.0 — August 2026

New Features & Improvements

  • Multi-Format Intake Engine: Native support for PDFs, Markdown, HTML, and plain text document loading.
  • Source Citation Tracking: Automatic metadata tagging for source file attribution in RAG responses.
  • Resilient Ingestion Pipeline: Graceful error handling for missing, corrupted, or unsupported file formats.

Bug Fixes

Resolved memory leak during large batch embeddings and fixed UTF-8 encoding fallback for legacy text files.
