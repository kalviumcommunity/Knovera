## Key Concepts Breakdown

### 1. What is a Text Embedding?
A text embedding is a dense vector of floating-point numbers (e.g., 1,536 coordinates) that represents the semantic meaning of a text sequence. Embeddings are generated by neural networks trained to project semantically related texts to nearby coordinates in vector space.

### 2. High-Dimensional Vector Spaces
- **Vector Dimension ($D$)**: The number of numeric coordinates in the vector (e.g., 1536 for OpenAI `text-embedding-3-small` / `text-embedding-ada-002`).
- **Coordinate Independence**: Individual coordinate values are generally not human-interpretable in isolation. Meaning is encoded in the continuous geometric pattern across all $D$ dimensions.
- **Uniformity**: Every input text processed by the same model outputs a vector of the exact same length $D$, regardless of whether the text is a 3-word sentence or a 500-token paragraph.

### 3. Cosine Similarity vs Euclidean Distance
- **Cosine Similarity**: Measures the cosine of the angle between two vectors ($\cos \theta = \frac{\mathbf{a} \cdot \mathbf{b}}{\|\mathbf{a}\| \|\mathbf{b}\|}$). Independent of vector magnitude, making it ideal for normalized text embeddings.
  - $\cos \theta = 1.0$: Identical direction (identical semantic meaning).
  - $\cos \theta = 0.0$: Orthogonal (completely unrelated concepts).
  - $\cos \theta = -1.0$: Opposite direction.
- **Euclidean Distance ($L2$)**: Measures straight-line distance between vector endpoints. For unit-normalized vectors ($\|\mathbf{a}\| = \|\mathbf{b}\| = 1$), Euclidean distance is monotonically related to cosine similarity: $\|a - b\|^2 = 2(1 - \cos \theta)$.

### 4. Why Embeddings Enable Semantic Search in RAG
1. **Synonym & Intent Matching**: Matches queries like "password reset" with chunks discussing "account credential recovery" without requiring exact keyword overlaps.
2. **Nearest-Neighbor Retrieval**: Vector databases (such as ChromaDB) index document vectors in spatial trees (HNSW / IVF) to find the Top-K closest document vectors to the query vector in milliseconds.
3. **Cross-Language & Multi-Lingual Potential**: Modern embedding models project equivalent concepts across languages into the same vector neighborhood.
