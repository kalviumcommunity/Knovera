# Knovera Enterprise IT & Cloud Access Guide
Department: Global IT & Infrastructure
Updated: September 2026

## 1. Remote Work & Secure VPN
- Employees accessing Knovera internal microservices from remote networks must connect via the Knovera WireGuard Enterprise VPN.
- Split-tunneling is disabled for corporate intellectual property endpoints.

## 2. Hardware & Device Management
- All corporate laptops must be enrolled in Knovera MDM (Mobile Device Management) with full-disk BitLocker or FileVault encryption.
- Installation of unapproved third-party browser extensions or unverified LLM tools is strictly prohibited on production workstations.

## 3. Incident Reporting
If you suspect a data spill, lost device, or prompt injection attack attempt:
1. Immediately notify security-ops@knovera.ai.
2. Dial the emergency security response desk at extension 4400.
3. Isolate the affected device from the local Wi-Fi network immediately.
