Key Takeaways on Non-Linear Tokenization:
  1. Standard English prose averages ~4 characters per token (~0.75 words per token).
  2. Long, technical, or un-common words split into multiple sub-word tokens (e.g. 'hyperparameterization').
  3. Code and JSON formatting contain spaces, quotes, colons, and brackets that increase token density.
  4. Multilingual text and Unicode emojis take multiple byte tokens per character, making them significantly more expensive.
